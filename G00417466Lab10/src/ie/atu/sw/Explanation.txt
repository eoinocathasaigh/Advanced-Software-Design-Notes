Today we see a divide between 2 db designs 
- Relational Database: one using Object relational mapping for the object graph to store it in a db: this one can relate things normally across tables using foreign keys but not a whole lot more object mapping besides
- Object Database: The other one uses a cache to store the object graph as it is in the relational db

The first way suffers from an Impedance Mismatch
The second doesnt

Most of the time we use the object relational mapping though since most of the time most of the info needs to be transacted 
- For doing this its very hard to get away from a relational database
