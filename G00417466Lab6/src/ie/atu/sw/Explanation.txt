MVC - Separation of concerns between 3 core components of a framework (Coarse grained instance of Single Responsibility Principle)

Model - Represents knowledge and may manifest as single object or complex aggregation of objects
View - Visualisation of all or part of model -> intended for human consumption and interaction, highlighting or hiding certain attributes of the model - tree -> hiearchial view
Controller - Intermediary between user of system and model. Receives requests from CRUD operations and sends them to model

We see the combination of patterns here:
Composite - Used to create the view -> tree like structure with hierarchial structure
Observer - Model handling/managing views being planted 
Strategy - configuring context, either an object model or with a view
